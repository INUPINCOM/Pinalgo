# Week 02. DFS & BFS (깊이/너비 우선 탐색)

## 이번 주 학습 목표
- **DFS / BFS의 본질:** 한 우물만 깊게 팔 것인가(DFS), 넓게 퍼지며 탐색할 것인가(BFS)?
- **핵심 스킬:** 재귀함수(Recursion)와 큐(Queue)의 활용법 익히기, **방문 처리(Visited)** 개념 완벽 숙지

<br>

## 🧠 본격적인 문제 풀이 전, 필독! (사전 지식)
이번 주 과제를 처음 접하면 코드가 외계어처럼 보일 수 있습니다. DFS와 BFS를 파이썬으로 구현하려면 아래 두 가지 도구가 반드시 필요합니다. 
**문제를 풀기 전, 유튜브나 구글에 아래 키워드를 꼭 한 번 검색해 보고 코드를 짜는 것을 강력히 추천합니다!**

1. **재귀함수 (Recursion)**
   - 함수 안에서 자기 자신을 다시 호출하는 기법입니다. (DFS의 핵심 무기)
   - ⚠️ 무한 루프에 빠지지 않도록 '탈출 조건(Base Case)'을 설정하는 것이 가장 중요합니다.
2. **큐 (Queue) 와 Deque**
   - 먼저 들어온 데이터가 먼저 나가는 선입선출(FIFO) 구조입니다. 
   - 파이썬에서 BFS를 구현할 때는 시간 초과를 막기 위해 리스트 대신 무조건 `from collections import deque`를 사용합니다. (검색 추천: *"파이썬 deque 사용법"*)
