# Week 03. 정렬 (Sorting)

## 이번 주 학습 목표
- **기본 정렬의 이해:** 각 언어에서 제공하는 내장 정렬 함수의 사용법과 시간 복잡도 이해하기
- **커스텀 정렬 (Custom Sort):** 오름차순/내림차순을 넘어, '내가 원하는 기준'대로 정렬하는 방법 터득하기

<br>

## 본격적인 문제 풀이 전, 필독! (사전 지식)
이번 주 과제는 단순히 숫자를 크기순으로 나열하는 것을 넘어섭니다. 본인이 사용하는 프로그래밍 언어(C++, Java, Python, JS 등)에 맞춰 아래 키워드를 꼭 먼저 검색해 보세요!

1. **사용자 정의 정렬 (Custom Comparator)**
   - 내장 정렬 함수에 '나만의 정렬 기준'을 적용하려면 어떻게 해야 할까요?
   - C++/Java의 `compare` 함수 오버로딩(Comparator), Python의 `key` 함수(lambda 또는 일반 함수), JS의 콜백 함수 등 본인 언어에 맞는 커스텀 정렬 구현법을 찾아보세요.
2. **다중 조건 정렬**
   - 기준이 2개 이상일 때는 어떻게 정렬할까요? (예: 1순위는 내림차순, 2순위는 오름차순)
3. **문자열 정렬의 특성**
   - 대부분의 언어에서 문자열 배열 `["3", "30", "34"]`를 정렬하면 숫자의 크기가 아닌 **사전순(앞자리가 큰 순서)**으로 정렬됩니다. 이 특성을 알면 '가장 큰 수' 문제를 훨씬 쉽게 접근할 수 있습니다.
