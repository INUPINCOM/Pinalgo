# Week 04. 이진 탐색 (Binary Search)

## 이번 주 학습 목표
- **O(log N)의 마법:** 10억 개의 데이터도 30번 만에 찾아내는 이진 탐색의 원리 이해하기 (Up & Down 게임)
- **파라메트릭 서치 (Parametric Search):** '원하는 값을 직접 찾는 문제'를 '이 값이 정답이 될 수 있는가?(O/X)'의 스무고개 문제로 바꾸어 푸는 실전 스킬 터득하기

<br>

## 본격적인 문제 풀이 전, 필독! (사전 지식)
이진 탐색은 코드가 짧지만, 무한 루프에 빠지기 쉬운 까다로운 알고리즘입니다. 문제를 풀기 전 아래 개념을 꼭 숙지해 주세요.

1. **절대 조건: 정렬**
   - 이진 탐색은 데이터가 반드시 **정렬된 상태**에서만 작동합니다. 
2. **이진 탐색 라이브러리 활용법**
   - 직접 `left`, `right`를 조작하는 방법도 알아야 하지만, 실전에서는 내장 라이브러리를 많이 씁니다.
   - Python의 `bisect`, C++의 `lower_bound` / `upper_bound` 사용법을 꼭 검색해 보세요. (이번 주 '순위 검색' 문제의 핵심입니다!)
3. **파라메트릭 서치 (매우 중요)**
   - 최적화 문제를 결정 문제로 바꾸는 마법입니다.
   - (예: "제한 시간 내에 퍼즐을 푸는 **최소 숙련도**는?" -> "내 숙련도가 X일 때, 제한 시간 내에 풀 수 있는가? **(Yes/No)**")
